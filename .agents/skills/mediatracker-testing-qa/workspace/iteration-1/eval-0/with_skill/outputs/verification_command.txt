Recommended Verification Command:
./gradlew :shared:jvmTest :shared:testDebugUnitTest

Rationale:
1. Authoritative Data Layer Run: This command is the only one that ensures the entire data layer—including Room DAOs, migrations, and repositories—is actually tested.
2. Avoids Silent Skips: The standard `./gradlew test` command (which resolves to :app:testDebugUnitTest and :shared:testDebugUnitTest) silently skips Room-touching tests in the shared module. These tests are explicitly excluded from the Android unit test variants because they require a real JVM environment to obtain a Room context, which only :shared:jvmTest provides.
3. Comprehensive Coverage: Running both :shared:jvmTest and :shared:testDebugUnitTest ensures that both JVM-specific data logic and common shared logic are verified.
