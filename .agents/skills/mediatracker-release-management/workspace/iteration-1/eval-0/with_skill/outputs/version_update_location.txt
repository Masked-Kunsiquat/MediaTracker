The version number should be updated in the `gradle/libs.versions.toml` file.

Specifically, update the `app` value under the `[versions]` block:

```toml
[versions]
app = "<next-version>"  # Increment this value (e.g., from 0.11.2 to 0.11.3)
```

This file serves as the single source of truth for the application version. The `app/build.gradle.kts` file automatically reads this value to derive both the `versionName` and the `versionCode` (using the formula `major*10000 + minor*100 + patch`). Do not manually edit the version in any other file.
